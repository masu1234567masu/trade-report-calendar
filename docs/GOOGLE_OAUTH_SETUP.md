# Google Cloud: OAuthクライアントID発行手順

このアプリ（トレード収支管理アプリ）がご自身のGoogleスプレッドシートを読み書きできるようにするための設定です。作業はすべて増田さんご自身のブラウザで、増田さんのGoogleアカウントを使って行います（Claude Codeは対話的なGoogleログインができないため代行できません）。

作業時間の目安：10〜15分。一度設定すれば以後は不要です。

---

## 1. Google Cloudプロジェクトを作成する

1. https://console.cloud.google.com/ を開く（増田さんのGoogleアカウントでログイン）
2. 画面上部のプロジェクト選択メニューから「新しいプロジェクト」
3. プロジェクト名を入力（例：`trade-report-calendar`）→「作成」
4. 作成したプロジェクトが選択されている状態にする（上部のプロジェクト名で確認）

## 2. Google Sheets APIを有効化する

1. 左メニュー（≡）→「APIとサービス」→「ライブラリ」
2. 検索窓で `Google Sheets API` を検索
3. 該当のAPIを開いて「有効にする」をクリック

## 3. OAuth同意画面を設定する

1. 「APIとサービス」→「OAuth同意画面」
2. User Type は **外部（External）** を選択→「作成」
   - 個人利用のみなので審査は不要（テストユーザーとして自分のアカウントを登録すればOK）
3. アプリ名：`トレード収支管理アプリ`（任意）、ユーザーサポートメール・デベロッパーの連絡先メールに増田さんのGoogleアカウントのメールアドレスを入力→「保存して次へ」
4. スコープ画面：何も追加せずそのまま「保存して次へ」（スコープはアプリ側のコードで指定します）
5. テストユーザー画面：「+ ADD USERS」で増田さんご自身のGoogleアカウントのメールアドレスを追加→「保存して次へ」
   - **重要**：これを忘れるとログイン時に「このアプリは確認されていません」からさらに進めずエラーになります
6. 概要を確認して「ダッシュボードに戻る」

## 4. OAuthクライアントIDを作成する

1. 「APIとサービス」→「認証情報」→上部の「+認証情報を作成」→「OAuthクライアントID」
2. アプリケーションの種類：**ウェブ アプリケーション**
3. 名前：任意（例：`trade-report-calendar web`）
4. 「承認済みのJavaScript生成元」に以下の2つを追加：
   - `https://masu1234567masu.github.io` （GitHub Pagesの本番URL）
   - `http://localhost:8000` （ローカルで動作確認する場合用。ポート番号は使うものに合わせる）
5. 「承認済みのリダイレクトURI」は**空のまま**でOK（今回の認証方式ではリダイレクトURIを使いません）
6. 「作成」をクリックすると、**クライアントID**が表示されます（`〜.apps.googleusercontent.com` という形式の文字列）
   - 「クライアントシークレット」も表示されますが、**今回は使いません**（クライアントIDだけで動く方式のため、シークレットは無視してOK・どこにも入力しません）

## 5. クライアントIDをアプリに設定する

発行された**クライアントID**（`〜.apps.googleusercontent.com`）をコピーして、増田さんに教えてもらうか、リポジトリの `config.js`（またはClaude Codeとのやり取り）に貼り付けてもらいます。

このクライアントIDは「公開されても問題ない」値です（ブラウザで動くアプリの仕組み上、コードに直接書いても安全です）。実際にスプレッドシートへアクセスするには、その都度増田さんご自身のGoogleアカウントでのログイン許可が必要になります。

## 6. 対象のスプレッドシートを準備する

1. Google Sheetsで新規スプレッドシートを作成（例：`トレード収支管理`）
2. URLの `https://docs.google.com/spreadsheets/d/【この部分】/edit` の【この部分】（スプレッドシートID）をコピーしておく
3. こちらもアプリの設定に使うので、Claude Codeに教えてください

---

### うまくいかないときの確認ポイント
- 「アクセスをブロックされました：このアプリは確認されていません」→ 手順3-5の「テストユーザー」に自分のアカウントを追加できているか確認
- ログインボタンを押しても何も起きない → 「承認済みのJavaScript生成元」に、実際にアクセスしているURL（`https://masu1234567masu.github.io` など、末尾スラッシュなし）が正確に登録されているか確認
- ローカル確認時は `http://localhost:ポート番号` を生成元に追加し忘れていないか確認
